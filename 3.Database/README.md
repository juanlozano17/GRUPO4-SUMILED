# Sentencias SQL: DDL y DML

## Contexto
En el desarrollo de bases de datos relacionales, las sentencias SQL se dividen en categorías según su función principal: estructurar la base de datos o manipular la información almacenada en ella.

---

### DDL (Data Definition Language)
* **Definición:** Lenguaje de Definición de Datos. Se utiliza para definir, crear, alterar o eliminar la estructura de los objetos de la base de datos (tablas, índices, vistas).
* **Comandos principales:** `CREATE`, `ALTER`, `DROP`, `TRUNCATE`

---

### DML (Data Manipulation Language)
* **Definición:** Lenguaje de Manipulación de Datos. Se utiliza para gestionar y manipular los datos que residen dentro de las tablas existentes.
* **Comandos principales:** `SELECT`, `INSERT`, `UPDATE`, `DELETE`
