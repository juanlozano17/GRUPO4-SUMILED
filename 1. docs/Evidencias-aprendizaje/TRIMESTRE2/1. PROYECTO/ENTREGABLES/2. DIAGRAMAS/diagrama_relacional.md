###  Diagrama Relacional de Base de Datos
El diagrama relacional representa la implementación física y lógica del esquema de base de datos. Muestra de forma detallada la estructura de las tablas, sus columnas, los tipos de datos asignados, las restricciones (*constraints*), así como las claves primarias (`PK`) y claves foráneas (`FK`) que enlazan las entidades para garantizar la integridad referencial.

* **Propósito:** Mapear la estructura relacional exacta que soporta el almacenamiento y la consulta eficiente de la información dentro del sistema.
* **Componentes clave:**
  * **Tablas y Columnas:** Definición clara de las entidades y sus atributos.
  * **Claves Primarias (PK):** Identificadores únicos para cada registro.
  * **Claves Foráneas (FK):** Enlaces e interconexiones que establecen las relaciones relacionales.
  * **Tipos de Datos y Restricciones:** Especificación de formatos (`VARCHAR`, `INT`, `DATETIME`, etc.), campos obligatorios (`NOT NULL`) y valores únicos (`UNIQUE`).
