### Diagrama de Despliegue
El diagrama de despliegue ilustra la arquitectura física de infraestructura y el entorno de ejecución donde interactúan los componentes del sistema. Describe la distribución de los artefactos de software (Frontend Web, API Backend y Base de Datos) en los distintos nodos de hardware, servidores o servicios en la nube, así como los protocolos de red empleados para la comunicación entre ellos.

* **Propósito:** Mostrar la topología física de la infraestructura, los entornos de hosting/servidores y las conexiones de red para la puesta en producción del sistema.
* **Componentes clave:**
  * **Nodos de Ejecución:** Servidores web, entornos de aplicación (p. ej., Node.js / servidor HTTP) y servidores de base de datos.
  * **Artefactos:** Compilados del cliente web (builds), código fuente/API del servidor y motor relacional de base de datos.
  * **Protocolos de Comunicación:** Enlaces e interfaces de red como HTTP/HTTPS, TCP/IP y conexiones JDBC/ORM.
