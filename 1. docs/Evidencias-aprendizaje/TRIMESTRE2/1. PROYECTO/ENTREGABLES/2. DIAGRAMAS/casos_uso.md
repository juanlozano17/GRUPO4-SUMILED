### 🎭 Diagrama de Casos de Uso
El diagrama de casos de uso representa los requerimientos funcionales del sistema desde la perspectiva de los actores que interactúan con él. Define los límites del software, las acciones específicas que los usuarios o sistemas externos pueden realizar y las relaciones de dependencia o extensión entre cada una de las funcionalidades.

* **Propósito:** Capturar el comportamiento esperado del sistema e ilustrar el alcance funcional para cada rol de usuario.
* **Componentes clave:**
  * **Actores:** Roles que interactúan con el sistema (p. ej., *Cliente*, *Administrador*, *Empleado*, *Sistema de Pagos*).
  * **Casos de Uso:** Funcionalidades o tareas específicas que ejecuta el sistema (p. ej., *Iniciar Sesión*, *Gestionar Inventario*, *Realizar Pedido*).
  * **Relaciones:** Conexiones de asociación entre actores y casos de uso, incluyendo relaciones de inclusión (`<<include>>`) para pasos obligatorios y de extensión (`<<extend>>`) para flujos opcionales o condicionales.
